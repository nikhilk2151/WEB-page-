# OmniLab Web Suite: Interactive Web Applications

A collection of 5 standalone, responsive, interactive HTML5 + CSS + JavaScript web applications featuring live 3D models, data explorers, decision matrices, presentation slide decks, and revision engines.

---

## 🌟 Included Applications

### 1. Launch Portal Hub (`index.html`)
The central navigation portal showcasing all applications with live feature cards, key highlights, and quick launch shortcuts.

### 2. Revision or Teaching Dashboard (`revision-dashboard.html`)
- **Topics to Tick Off:** Categorized syllabus checklist with progress tracking and `localStorage` persistence.
- **Mission Timers:** Exam target countdown clock + customizable Pomodoro focus timer (25 min study / 5 min break) with Web Audio sound alerts.
- **3D Flip-Cards:** Interactive flashcards with formula derivations and Spacebar flip shortcut.
- **Scored Quiz:** 5-question knowledge check with instant feedback, explanations, score breakdown, and rank badges.

### 3. Money Explorer (`money-explorer.html`)
- **Spending by Category:** Interactive SVG donut chart and monthly budget cap meters.
- **Duplicates to Check:** Algorithmic duplicate transaction detector with "Refund / Remove" and "Keep Both" resolution actions.
- **Savings Slider Simulator:** Compound interest what-if engine with sliders for discretionary cutbacks, monthly contributions, APY, and time horizon + dynamic growth curve.
- **Transaction Ledger:** Searchable, filterable ledger with modal to add new expenses and CSV export.

### 4. Interactive 2D / 3D Model (`interactive-model.html`)
- **🪐 3D Solar System (Three.js WebGL):** 360° mouse drag to rotate, scroll wheel to zoom, all 8 planets + Sun + Saturn's rings + Earth's Moon, orbit paths, speed slider (0x to 5x), and ISRO mission telemetry.
- **⚡ Electric Circuit Lab (2D Physics):** Closed-loop canvas circuit with battery, potentiometer resistor, knife switch, LED bulb glow, and live Ohm's law ($I = V/R$, $P = VI$) multimeter.
- **🫀 Human Heart Anatomy & Cardiac Cycle:** Pumping 4-chamber anatomical heart with BPM slider (40–180), systole/diastole indicator, and synthesized "Lub-Dub" heartbeat sound.

### 5. Decision Helper (`decision-helper.html`)
- **Compare 3–5 Options:** Pre-loaded decision templates (Cloud Architecture, ISRO Rockets, Universities, Workstations).
- **Live Weighted Sliders:** Criteria importance sliders that recalculate composite scores and smoothly re-rank candidate options in real time.
- **Multi-Attribute Radar Chart:** Canvas spider chart comparing the top options across all dimensions.
- **Score Matrix:** Heatmap comparison breakdown with printable export.

### 6. Interactive Presentation (`interactive-presentation.html`)
- **10-Slide Deck:** Full keyboard navigation ([`←`], [`→`], [`Space`]), progress bar, and slide counter.
- **Live Interactive Chart (Slide 4):** SVG multi-series chart with category toggles and a projected growth multiplier slider.
- **Live Audience Quiz (Slide 8):** Embedded interactive question with real-time score tracking.
- **Presenter Tools:** Fullscreen mode ([`F`]), slide overview grid ([`O`]), and elapsed presentation timer.

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/nikhilk2151/WEB-page-.git
   ```
2. Open `index.html` directly in any modern browser (Chrome, Edge, Firefox, Safari).
3. No build tools, package managers, or local servers are required!
